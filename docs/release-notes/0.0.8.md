# Release notes for version 0.0.8

## 🔒 Privacy

- **Self-hosted fonts**: SitHub no longer loads Inter from Google Fonts. The four Inter weights used
  by the interface, including Cyrillic glyphs for Ukrainian, are now embedded in the binary with the
  existing Material Design Icons font. Browsers no longer contact `fonts.googleapis.com` or
  `fonts.gstatic.com`
- **Stricter Content Security Policy**: the CSP no longer permits Google Fonts stylesheet or font
  hosts. Fonts are limited to `'self'` and `data:`
- **Font license**: the Inter OFL 1.1 copyright and license notice ships with the embedded assets at
  `/licenses/inter-OFL-1.1.txt`

## 🔩 Improvements

- **Security updates**: Echo 4.16.6 and `golang.org/x/net` 0.63.0 resolve advisories reported by the
  backend security scan. Frontend dependency updates resolve npm audit and Trivy findings, including
  high-severity advisories in `systeminformation` and `undici`
- **Dependency refresh**: Pinia 4.0.3, Vue Router 5.5.1, Cypress 16.1.1, jsdom 30.1.2,
  `eslint-plugin-vue` 10.12.1, and `@vue/test-utils` 2.6.0
- **Test reliability**: new regression tests check embedded font assets, CSP directives, and real
  browser loading with a cold cache and third-party requests blocked. The live-feed WebSocket test now
  waits for client registration before broadcasting

## ⬆️ Upgrade Notes

- **Custom CSP overrides**: if a reverse proxy replaces SitHub's Content Security Policy, remove any
  `fonts.googleapis.com` and `fonts.gstatic.com` allowances; they are no longer needed
- **Self-compiled binaries**: run `npm ci && npm run build` in `web/` before building the Go binary
  so the font assets are embedded
- No database migrations or configuration changes are required.
