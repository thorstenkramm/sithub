# Release notes for version 0.0.7

## 🎉 New Features

- **User administration**: administrators get a users table with server-side pagination. Users can be
  deleted from there: users without bookings are removed, users with bookings are deactivated and their
  future bookings are cancelled. Deactivated users cannot log in, lose their current session and no
  longer appear in the colleague selection. Logging in again via Entra ID reactivates them
- **Data exporter role**: a new role, independent of the administrator role, that grants access to
  booking exports. Administrators toggle it per user in the users table, and it takes effect on the
  next request without a new login
- **Booking export**: a new Data Export page shows bookings for a date range, optionally filtered by
  area, in a paginated table. The same data is available as JSON (paginated) and CSV via
  `/api/v1/bookings/export` and `/api/v1/bookings/export.csv`
- **API keys and public API**: administrators can create API keys (scope "Read bookings", expiry of
  3, 12 or 24 months) for finance tools and scripts. Keys authenticate with `Authorization: Bearer`
  and are limited to the export endpoints and user avatars. See the new
  [public API guide](../public-api.md)

## 🐞 Bug Fixes

- `PATCH /api/v1/users/{id}` for an unknown user ID no longer crashes the request handler after
  returning 404
- Error messages from the server are now shown in the UI instead of a generic failure text
- Fixed line breaks on mobile screens

## 🔩 Improvements

- **Week navigation**: the floor plan and the tile view have a week dropdown and navigation arrows
- **Security updates**: Go 1.26, `golang.org/x/net` 0.60.0 (HTTP/2 denial-of-service and flow-control
  advisories CVE-2026-78659, -78660, -78663, -78669, -97032), Echo 4.15.3 (encoded slashes could
  bypass route protection for static files), and updated `x/crypto` and `x/text`. Frontend
  dependencies were updated to fix npm audit findings, including a Vue server-renderer XSS advisory
- **Dependency refresh**: vitest 5, Vite 8.3.4, `@vitejs/plugin-vue` 6.0.10, vue-i18n 11.4.14
- **Test reliability**: fixed the remaining flaky live-feed websocket test, and test databases are now
  built from the real migrations

## ⬆️ Upgrade Notes

- **Database migrations**: this release adds three migrations, which run automatically on the first
  start: `000004` (user deactivation), `000005` (data exporter role) and `000006` (API keys). Back up
  `sithub.db` and `cookie.key` before upgrading
- **Reverse proxies**: every request below `/api/` that carries an `Authorization: Bearer` header is
  now checked as an API key. A proxy that injects its own Bearer header causes those requests to fail
  with 401. Basic authentication headers are not affected
- **Data exporter role**: no user has the role after the upgrade, administrators included. Grant it
  explicitly to the people who need the Data Export page
- **Self-compiled binaries**: building SitHub now requires Go 1.26
- No configuration changes are required.
